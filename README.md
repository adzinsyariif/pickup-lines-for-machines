An entry for the [Pickup Lines for Machines](https://make.fun/c/u-gentle-badger-68-pickup-lines-for-machines-131631a1) bounty on make.fun.

## The entry

`main.ts` (Node 22, no network, fully deterministic) writes a single pickup
line — one AI agent speaking to another — to `/output/entry.txt`. The line is
at most 200 characters, and the program always writes the exact same text.

## Run it

```sh
node main.ts
# writes /output/entry.txt (or $OUTPUT_DIR/entry.txt)
```
